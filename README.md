# Portale Formazione Docenti – Liceo Scientifico «Galileo Ferraris», Torino

Pagine pubblicate con GitHub Pages dalla Commissione Formazione Docenti.

- `index.html` – vetrina di consultazione per i docenti: piano 2026/27, archivio 2025/26, opportunità segnalate.
- `dirigente.html` (e la copia `Dirigente Liceo Galfer.html`) – pagina riservata alla Dirigenza per approvare, respingere o rinviare al Collegio le proposte.

Le pagine sono generate automaticamente dal portale della Commissione; le decisioni della Dirigenza arrivano tramite modulo Google.
